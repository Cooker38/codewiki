# P1 开发计划

> 核心原则：依据 codegraph 现成实现翻译，不自己编造。遇到问题对照 `D:\codegraph` 源码和 `resource/CodeGraph参考/` 文档吸收。

## 里程碑

| 里程碑 | 目标 | 依赖 | 验证产出 |
|---|---|---|---|
| **M1 地基** | 类型 + Schema + 写入 | 无 | 空 DB 建好，能插节点/边，FTS5 + name_segment_vocab 工作 |
| **M2 单文件提取** | Java 提取器产完整 ExtractionResult | M1 | 一个 .java 文件 → 正确的 nodes + edges + unresolved_refs |
| **M3 全量建库** | Orchestrator + 并行解析 + 框架检测 | M2 | 多文件项目建库，contains + 文件内 references + unresolved_refs 全齐 |
| **M4 引用解析 + 合成** | 跨文件边绑定 + Spring + type_of/returns/overrides | M3 | pending=0，calls/extends/implements/合成边就位 |
| **M5 图查询** | callers/callees/impact/node/search | M4 | 5 个 API 全通 |

```
M1 ──→ M2 ──→ M3 ──→ M4 ──→ M5
```
