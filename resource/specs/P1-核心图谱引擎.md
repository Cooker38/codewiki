# P1 核心图谱引擎 — Spec

> codegraph 的完整 Python 移植。对 Java 项目源码输出等价 SQLite 图谱，提供图查询 API。

## 收敛目标

## 约束

1. Schema 及 node ID 与 codegraph 一字不差
2. 提取逻辑对齐 Java 提取器的全部节点类型、Lombok 合成、返回类型归一化
3. 解析管线：扫描 → 框架检测 → 并行解析 → 按序落库 → 引用解析 → 合成层
4. 引用解析全策略链，unresolved_refs 状态机完整 (pending → resolved(删) / failed(留 name_tail))
5. 图遍历：先 visited 后深度 (#1086/#1089)，callers 计入 instantiates，impact 排除 contains
6. 边 provenance：tree-sitter (AST 阶段) / heuristic (合成阶段)
7. 文件记录含 content_hash，updated_at 用 Unix 毫秒时间戳
8. 级联删除：FK ON DELETE CASCADE

## 验收标准

| # | 验收项 | 验证方法 |
|---|---|---|
| 1 | Schema 完整 | 6 表 + FTS5 + 3 触发器 + 全部索引存在 |
| 2 | 建库成功 | Java 项目跑建库，nodes/files/unresolved_refs 均有数据 |
| 3 | Node 字段完整 | class/method 节点含 qualified_name/signature/docstring/visibility/return_type |
| 4 | contains 层级正确 | file→class→method→parameter 链完整 |
| 5 | 文件内 references | 同文件 method→field 的 references 边存在 |
| 6 | 跨文件 calls | 建库后 unresolved_refs pending=0，edges 有跨文件 calls 边 |
| 7 | extends/implements | 继承/实现边正确绑定 |
| 8 | Spring 框架 | Spring Boot 项目可检测，@Bean/@Autowired 自动合成实例化/调用边 |
| 9 | Lombok | @Getter/@Setter/@Builder 项目，nodes 有合成 field/method + 对应 edges |
| 10 | type_of/returns/overrides | 合成层边存在，provenance='heuristic' |
| 11 | callers 正确 | 计入 instantiates，结果含调用方 + 实例化方 |
| 12 | impact 不含 contains | impact(类) 不含内部 method/field |
| 13 | search | FTS5 搜索返回 score + file:line |
| 14 | name_segment_vocab | 表非空，segment 正确拆分自符号名 |
| 15 | idempotent | 两次建库结果一致，边不翻倍、节点不重复 |
